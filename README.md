# BlackMamba | Applied AI & Cybersecurity

Independent engineering portfolio and proposed research roadmap for secure, edge-first AI systems. Not affiliated with OpenAI or claiming production readiness.

## Mission
Architect intelligence, secure it, and deploy it at the edge.

## Programs
See [program index](PROGRAM_INDEX.md), [architecture](ARCHITECTURE.md), [roadmap](ROADMAP.md), and [security policy](SECURITY.md).

## Evidence standard
Every implementation must include reproducible tests, threat model, measured performance, limitations, and deployment instructions. Planned work is not represented as completed.

## First milestone
A local inference adapter, deny-by-default agent permissions, synthetic security-event triage, and reproducible evaluation. No live targets or sensitive data.
