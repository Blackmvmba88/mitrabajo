# Roadmap

1. Inventory existing work; identify reusable licensed assets.
2. MVP: local inference adapter, permission kernel, synthetic event triage, benchmark harness.
3. Security: isolation, adversarial evaluation, audit and human approval.
4. Hybrid: privacy-aware routing, offline fallback and observability.
5. Enterprise: documented integration SDK, partner sandbox, reference deployment.
6. Research: controlled experiments and published limitations.

Exit criteria for every phase: reproducible tests, documented threat model, measured results, versioned evidence and peer review. No invented performance claims.
