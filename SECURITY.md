# Security policy

Use only owned or explicitly authorized environments. Do not commit credentials, personal information, employer-confidential material, or live incident logs. Use synthetic fixtures. Report suspected vulnerabilities privately using GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately. Do not disclose exploit details in public issues.

Agents default to no permissions. Require human approval for consequential writes. Limit runtime, network and filesystem access. Record redacted audit events. No production readiness claim.
